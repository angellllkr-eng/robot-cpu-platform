# A.K. Precision Robotics

Premium founder-led landing site for the A.K. Precision Robotics initiative.

The site positions the robotics layer alongside the platform's operating architecture:

- **A11-K** — operating intelligence: verify, know, risk, decide, govern, secure, observe.
- **MindReply** — operating presence: discover, build, sell, deliver, scale.
- **Founder** — the will: authorize, direct, and own outcomes.

## Local development

```bash
pnpm install
pnpm dev
```

The frontend is a self-contained Vite + React experience. Its generated hero artwork is served from Manus storage in the hosted WebDev environment; those asset URLs intentionally remain external to this repository so large media is not committed to Git.

## Validation

```bash
pnpm check
pnpm build
```
